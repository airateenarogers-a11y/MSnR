# V5 update: install and run

1. Keep MT5 open and logged into your **demo** account. Enable Algo Trading and allow external Python trading in MT5 settings.
2. Close the old **MSnR Local control center**. Download the new [Install-MSnR.cmd](https://github.com/airateenarogers-a11y/MSnR/raw/main/Install-MSnR.cmd) and run it. Do not reuse an older downloaded copy.
3. The installer backs up the application and preserves credentials, journals and risk settings. Desktop startup migrates the policy to v5 and keeps a `var/desktop/demo-config.pre-v5.json` backup. Existing trades are still reconciled; old-policy signals cannot authorize new orders.
4. Click **Check MT5 (read only)**. The report must show actual bid/ask and M1 candles. If it fails, **Copy MT5 report** gives the exact failing native operation without account passwords. Opening charts in MT5 alone does not verify the Python connection.
5. Click **Open dashboard**. Confirm fresh prices and a running worker. Automatic **demo** execution is enabled when every strategy and risk condition passes. Live accounts are blocked.
6. If a previous critical error left execution suspended, inspect the report and reconciliation status, then use Settings → **Clear reviewed error suspension**. A kill switch or unresolved order continues to block execution.

Tokens and the local bridge address are generated by the launcher. You do not need to invent or paste them manually. Keep the control center running; closing it stops its services. Discord is optional and configured locally with **Configure Discord**.

## Risk settings

`evaluation_mode=false` uses the funded profile with a 0.50% hard ceiling. The evaluation profile permits the user-approved 0.33/0.50/1.00% ladder. This setting is independent of demo/live account mode. Existing per-trade limits are preserved; the default 0.33% ceiling still limits higher phases unless explicitly raised in Settings. `evaluation_target_fraction` is a decimal, e.g. `0.10` for 10%. Other loss/exposure limits always apply.

## Optional TradingView workspace annotations

Discord charts use the exact MT5 OHLC data. TradingView is an additional visualization, not an order authority.

Launch a **dedicated** Chrome profile from Windows Command Prompt (adjust the Chrome executable path if necessary):

```bat
"C:\Program Files\Google\Chrome\Application\chrome.exe" --remote-debugging-address=127.0.0.1 --remote-debugging-port=9222 --user-data-dir="%LOCALAPPDATA%\MSnR-TV" https://www.tradingview.com/chart/O7UQR2ba/
```

Sign into TradingView in that window. Select the exact signal instrument/feed and timeframe. From the installed app folder run:

```bat
.venv\Scripts\python.exe -m msnr.cli --db var/desktop/demo.db tradingview-draw SIGNAL_ID --symbol EXACT_EXCHANGE:SYMBOL
```

Replace both placeholders with the recorded signal UUID and exact TradingView symbol. The command refuses a different symbol/timeframe, unavailable API, or inaccurate anchors. Native anchor readback is tested before/after zoom and pan. Changing timeframes requires re-running on the correct signal timeframe; invariance across timeframe changes is not claimed. The browser API may be unavailable on your layout. Never expose Chrome's debugging port to the internet.

## What is and is not verified

V5 replaces the legacy mapping, global hybrid filters, sessions, Fibonacci ratios and risk ladder. It includes model-specific entry-zone badges, developing ERS support and the latest EX definitions. Required TP1 reward/risk is 2–3R at the first opposing fresh level; a closer target rejects rather than being skipped. Tests use synthetic fixtures and establish engineering behavior, not profitability.

Actual laptop MT5 connectivity, broker fills, logged-in TradingView API availability, and complete historical validation of every named model remain unverified from this cloud environment. QT's exact 22.5-minute boundaries require sub-minute data; the current M1 feed cannot prove that range, so QT_SMT is blocked. Advanced storyline exhaustion requires complete-history attestation. Generic MSS alternatives and all eight trendline classifications lack complete end-to-end coverage. Do not interpret this release as 100% strategy coverage or production certification. See [compliance matrix](COMPLIANCE_V5.md) and [audit](STRATEGY_V5_AUDIT.md).
